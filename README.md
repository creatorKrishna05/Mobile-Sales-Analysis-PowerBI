# 📱 MOBILE SALES ANALYSIS DASHBOARD – POWER BI

## 📌 PROJECT OVERVIEW
This project presents an interactive **Mobile Sales Analysis Dashboard** built using Microsoft Power BI. It analyzes mobile sales data to understand sales performance, customer behavior, product trends, and payment preferences.

## 🎯 PROJECT OBJECTIVES
- Analyze total sales and quantity sold.
- Track total transactions and average sales.
- Identify top-performing mobile brands and models.
- Analyze city-wise and monthly sales performance.
- Understand customer ratings and payment preferences.

## 📊 KEY PERFORMANCE INDICATORS (KPIs)
- **Total Sales**
- **Total Quantity Sold**
- **Total Transactions**
- **Average Sales**

## 📈 DASHBOARD FEATURES
- Monthly Quantity Analysis
- City-wise Sales Analysis
- Brand-wise Sales Performance
- Mobile Model-wise Analysis
- Payment Method Analysis
- Customer Ratings Analysis
- Day-wise Sales Trends
- Interactive Filters and Slicers

## 🛠️ TOOLS & TECHNOLOGIES
- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Excel
